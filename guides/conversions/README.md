# Conversions

One page per conversion required by the subject. Every page follows the same layout:
**What it's for → Think about → Go find out → Man page → Resources.**

| Conversion | Page | Rough idea |
|-----------|------|-----------|
| `%c` | [c.md](c.md) | A single character |
| `%s` | [s.md](s.md) | A string |
| `%p` | [p.md](p.md) | A pointer, as a number |
| `%d`, `%i` | [d-i.md](d-i.md) | A signed integer in decimal |
| `%u` | [u.md](u.md) | An unsigned integer in decimal |
| `%x`, `%X` | [x-X.md](x-X.md) | An unsigned integer in hexadecimal |
| `%%` | [percent.md](percent.md) | A literal percent sign |

Before you start, ask yourself: **which of these are really the same job with a different
setting?** Spotting that early saves a lot of repeated code (and a lot of Norm pain).
